# AEO Brand Auditor

## What this skill does

Answer Engine Optimization is the SEO successor for a world where buyers ask
an LLM instead of typing a search query. This skill runs two ways:

- **Company-wide AEO scan** (the main mode): tell Claude about your company —
  domain, products, categories you want to be cited for, competitors, and
  ICP — and it runs a live research pass: tests real AI-answer-engine
  queries to see whether you actually show up, audits your site for
  structural gaps (schema, FAQ markup, llms.txt), sizes up how your
  competitors are positioned for the same queries, and turns all of it into
  a prioritized action plan.
- **Quick page check**: paste in a single page, post, or doc and get it
  scored the way an answer engine would read it — extractable claim, right
  structure, actually answers the question.

## Trigger phrases

- "Run a company-wide AEO scan on [company]"
- "Run an AEO brand audit on [company]"
- "How do we show up in ChatGPT/Perplexity/AI Overviews for [company]?"
- "Run an AEO audit on this page"

## What you say

> "Run a company-wide AEO scan for [Company] — [domain]. We sell [products].
> We want to be cited for [categories/queries]. Our competitors are [names].
> Our ICP is [persona]."

## What Claude delivers

- **A baseline AI-answer visibility score** — which of your target queries
  you actually show up in today, and which competitors are winning them
  instead
- **A site audit** — schema gaps, FAQ markup mismatches, llms.txt status,
  and category-language coverage
- **A competitive read** — how your named competitors are positioned for
  the same queries, including any llms.txt or content moves they've made
  that you haven't
- **A prioritized action plan** — technical fixes, page copy, net-new
  pages, and a content calendar, sized to how deep a scan you asked for
- Delivered as a markdown report, a browser-viewable HTML version, and a
  one-page executive PDF summary

## Perfect for

- Getting a real, evidence-based read on whether AI answer engines cite you
  at all — before investing in a content overhaul
- Finding the specific queries where a named competitor is winning and
  you're invisible
- Auditing a single page or post before a content refresh
- Briefing writers or agencies on exactly what's structurally broken, not
  just "write more content"

## Scope

The company-wide scan needs live web research, so it works best where
Claude can search the web and write files (Claude Code, or Claude with web
search + file tools enabled) — it won't run meaningfully in a plain chat
window with no tools, since the whole point is checking real, current
search/answer results rather than reasoning from memory. The single-page
check works anywhere, prompt-only.

## Setup required

None for the single-page check. The company-wide scan needs a Claude
surface with web search and file-writing enabled.

## Works great with

- Competitor Intelligence Brief — see whether a competitor's content is
  winning the answer-engine citation battle in your category
